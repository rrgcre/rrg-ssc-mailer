Email Templates — Help & User Guide

A template is an email you write once and reuse — a buyer intro, an NDA follow-up, a seller check-in. Templates show up in the send composer on any contact and as the message an automation sends, so your team sends the same polished, personalized email every time. This guide covers writing them, personalizing with merge fields, sharing them, and keeping a growing library organized with folders.

1 Overview

Email Templates live under Marketing Machine → Email Templates.

The page is a wide list of every template you can use — your own and any your firm has shared. A folder rail on the left keeps a growing library organized; the list on the right shows each template's name, folder, visibility, subject and owner. Click + New template to write one, or edit fields right in the row (see Edit in the list).

2 Write once, reuse everywhere

The whole point of a template is that you never retype the same email.

Once saved, a template is available in two places: the send composer on a contact (pick the template, it fills in the subject and body personalized to that person), and as the message body of an automation step (see Templates & automations). Write the email carefully once — tone, structure, call to action — and every send after that is one click.

3 Merge fields (tokens)

Tokens make a canned email read like you wrote it just for that person.

Drop a token anywhere in the subject or body and it fills in when the email is sent. The common ones:

  • Contact: {{first_name}}, {{last_name}}, {{name}}, {{company}}, {{title}}, {{email}}, {{phone}}
  • You (sender): {{my_name}}, {{my_title}}, {{my_phone}}, {{my_email}}
  • Listing: {{listing_name}}, {{listing_number}}
  • Other: {{today}}
Tip
If a token has no value for a given contact (say a buyer with no company), it's left blank rather than printing the raw {{token}} — so a missing field never looks broken.

4 Personal vs Shared

Every template is either yours alone or the whole firm's.

Personal templates are visible and editable only by you. Shared templates are firm-wide — everyone can use them, so the team sends a consistent, on-brand message. Only admins can publish a template as Shared; save yours as Personal, or ask an admin to publish it firm-wide. You can only edit or delete templates you own — a teammate's Shared template opens read-only, and you can spin your own copy off it with + New template.

5 Folders

As the library grows, folders keep it findable.

The folder rail on the left lists your folders with a count on each, plus All templates and Unfiled. Click a folder to filter the list to just its templates. Use the + at the top of the rail to create a folder; hover a folder for ✎ rename and × delete. Folders are one level (flat) and team-wide — everyone sees the same structure.

File a template into a folder two ways: click its Folder cell in the list and pick one, or set the Folder field in the full editor. Creating a new template while a folder is selected files it there automatically.

Deleting a folder
Deleting a folder never deletes templates — the templates in it simply become Unfiled. Rename a folder and every template in it follows.

6 Edit right in the list

Quick changes don't need the full editor.

On your own templates, click the name, folder, subject, or visibility cell right in the row to edit it in place — type and press Enter (or click away) to save; Esc cancels. Folder and visibility are dropdowns. Only the field you touch is saved, so the email body is never affected. For the body itself, open the full editor with Edit.

7 The full editor

Open a template with Edit (or + New template) to write the body and set everything at once.

The editor holds the template name, visibility, folder, subject, and the body — a rich-text field with formatting and a merge-field menu. Save writes it back to the list; Delete removes it (owner only, with a confirm). Close returns to the list without changes.

8 Templates & automations

Templates are the messages your automations send.

When you build an automation that emails a contact — a new-lead follow-up, a drip sequence, a post-tour note — the email it sends is a template. Write and refine the message once here, and any automation step can use it, so a change to the template updates every sequence that references it. Build automations under Marketing Machine → Automations.

9 FAQ

Why can't I make a template Shared?

Publishing firm-wide is admin-only, so a stray personal draft doesn't go out to the whole team. Save it Personal, or ask an admin to publish it Shared.

I edited a shared template and it wouldn't save.

You can only edit templates you own. A teammate's Shared template is read-only for you — use + New template to make your own copy and edit that.

Do I lose the body when I edit a field in the list?

No. An inline edit saves only the field you changed; the body and everything else are preserved untouched.

Can I nest folders inside folders?

Not today — folders are one level. If your library outgrows a flat structure, a nested-folder view can be added on top of this.

A token printed as literal text in a sent email.

Check the token spelling against the list in Merge fields — an unrecognized token (a typo, or one that doesn't exist) is left as written. Recognized tokens with no value are blanked, not printed.
