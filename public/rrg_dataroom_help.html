Data Room — Help & User Guide

The Data Room is your confidential deal room: the place an NDA'd buyer reviews a listing's documents, and where you control who sees what and watch exactly who's serious. Everything here is confidential by default — nothing is exposed to a buyer until they're vetted and gated. This guide walks through every part of it, start to finish.

Business SalesConfidential by defaultBuyer engagement trackingNo buyer app required

1 Overview

A data room (VDR — virtual data room) is a private, per-listing document vault with a shareable buyer link. You load the seller's financials, lease, licenses, and other diligence documents once; qualified buyers review them under NDA; and you get a running record of who opened what, when, and for how long.

The core idea

  • Confidential by default — a buyer sees nothing until you've authorized them. The room is public-but-gated: there's a link, but a personal access code is what actually opens it.
  • No buyer account, no app — buyers never sign in to the platform. They click a link, enter a code, and they're in. That keeps the barrier low for serious buyers and the wall high for everyone else.
  • Tied to the deal — each room links back to its listing/company, so access and engagement live right alongside your pipeline, offers, tours, and NDAs.
  • Every move is logged — views, downloads, read time, and questions are all captured so your follow-up is driven by real behavior, not guesswork.

Reading the Data Rooms list

The Data Rooms list shows each room's status at a glance: a green ● Live badge means the room is active and has documents (ready to share), a blue 🔗 Shared badge means at least one buyer has been given access (hover for the buyer count), and a grey Setup badge means the room is still being assembled. The quick-view chips above the list — All rooms, Live, Setup, and Shared — match those badges so you can filter to exactly the state you care about. The search box finds a room by name, creator, or buyer.

Who this guide is for
Brokers and reps who set up and run data rooms. Buyers don't need a manual — they just receive a link and a code from you.

2 Creating a data room

There are three ways a room comes into being, depending on where you are in the deal.

A. From a seller screening call

When a seller qualification call moves forward to a business sale, a data room can be spun up from that call, carrying the seller's details across so you're not re-typing them.

B. From a listing's marketing pack / CIM

Generate the room straight from a listing's marketing pack or CIM microsite, so the room and the offering stay tied together.

C. Standalone — the "+ New data room" button

On the Data Rooms page, use + New data room (top-right of the list). It's also reachable from the header's Create New → Data Room, and when the list is empty a + New data room button appears in the center of the page as a shortcut. All three open the same form. You'll capture the originating details up front:

  1. Contact — the seller/contact this room belongs to (searchable against your book of business; now required).
  2. Listing — optionally link the room to an existing listing.
  3. Rep — who's running the deal.
  4. Date — when the room is opened.
  5. Per-year subfolders — optionally seed each Financials year with sub-periods: None, 12 calendar months (+ Full Year), or 13 four-week periods (+ Full Year — the standard restaurant fiscal calendar). Every Financials year also carries a T12 (trailing-twelve-month) folder automatically.
  6. Customize folders… — for full control, open the folder picker and check exactly which folders the room should start with (every section, each year, and each month/period). You can always add, rename, or remove folders later.
  7. Left as-is, the room is created with the standard folder structure already in place — no building from scratch.
Best practice
Link the room to the real seller contact when you create it. That's what powers the "Data Room · [Business]" title, the access email personalization, and the tie-back to the deal record.

Renaming a room

A room's name isn't locked in. Use the ✎ Rename control next to the title at the top of the room to edit it inline and save — handy when a room was created with a placeholder name or the wrong business. The new name flows straight into the "Data Room · [Business]" title everywhere it appears.

Building your own folders

The standard set is a starting point, not a straitjacket. Inside a room you can + New folder at the top level, add a + Subfolder under any folder (nest as deep as you need), Rename a folder, or remove one with the trash control — deleting a folder never deletes its files, they simply fall back to the room's root level. Use each file's Move to a folder dropdown to file it anywhere, or choose Root to pull it up alongside the main folders.

Renaming files

Every file has a Rename control next to it — click it, type a clearer name, and it updates everywhere, including the watermarked copy a buyer downloads.

Opens closed, remembers your layout

A room opens with all folders collapsed so you see the full structure at a glance; click any folder to expand it. Your open/closed layout is remembered per room after the first visit — for you internally, and separately for each buyer on their own link.

You can move documents between folders and delete them at any time. To refile a batch, tick the checkbox on each file and use Move selected to… to move the whole selection into one folder in a single step. You can also drag any file straight onto a folder (or onto Root) to move it there — drag one of several checked files and they all move together. If a deal genuinely has no lease (owner-occupied or N/A), flag it with the "No lease" toggle so the structure stays honest and the missing folder doesn't read as a gap.

4 Getting documents in

Several ways to load a room — pick whichever is fastest for the batch in front of you.

Drag & drop

Just drag files from your desktop straight onto the room page — anywhere works. A drop overlay appears; let go and the batch runs through AI auto-filing, sorting each into the right folder. It is the fastest way to load a room.

Single upload

Name a file, drop it into the right section. Supported: PDF, Word, Excel, CSV, PowerPoint, images, and text — up to 25 MB each.

Bulk upload with AI auto-filing

Drop in a batch of up to 40 files at once. The assistant reads each one and files it into the correct folder automatically. Anything it gets wrong, you fix in a click with the folder controls.

ZIP files (opt-in per room)

By default a room won't accept a .zip — a loose zip is a black box a buyer can't preview and you can't track per-document. Turn on Allow ZIP files in the room's Add-documents panel to change that for a given room. With it on, uploading a zip asks how to handle it: unzip & file the contents (each PDF/Excel/etc. becomes a real, trackable, previewable document, auto-filed by name), store the zip as-is (a single download-only item), or both. Junk entries (__MACOSX, .DS_Store, desktop.ini) are skipped, and each extracted file still obeys the 25 MB per-file limit.

Duplicate detection

When you upload, the room checks for duplicates — both an exact file match and the same document already sitting in a folder — and warns you before it adds a second copy, so a room doesn't fill up with "P&L (1).pdf, P&L (2).pdf." You can override and upload anyway if it's genuinely a new version.

Buyer / seller upload by link

Give a person Edit rights on a folder and they can upload into it through the room link — see Inviting buyers & access. This is how a seller sends you their financials, or a buyer returns a signed document.

Heads up
Upload is a folder-level right. A person can only upload into a folder you've set to Edit for them — not the whole room.

5 Inviting buyers & access

Each buyer is authorized individually and gets their own access code — their password to open the room.

  1. Add the buyer under Buyers & access — name and email. The buyer is a contact in your book, so you can search an existing contact to link rather than creating a duplicate.
  2. Set a starting access level — No access (choose folders), View only, View & download, or View, download & upload. You can fine-tune per folder afterward.
  3. Authorize — this generates the buyer's personal access code and, importantly, locks the room (see the warning below).
  4. Email access — click Email access on the buyer's row to send them the room link, their access code, and an upload note in one email. The button reads "Re-send email" afterward.
  5. They're in — the buyer opens the link, enters the code, and reviews exactly the folders and files you granted. Everything they do is logged.

People-with-access roster

The room shows a live roster of everyone granted access: name, email, company, their access level, their code, when access was granted, when they were last seen, and their view/download counts — each with Email access and Revoke right there.

Authorizing the first buyer locks the room
The moment you authorize the first buyer, the plain shared link stops working on its own — from then on a personal access code is required to get in. That's the confidentiality gate, and it's by design.
Best practice
Add an email for every buyer. The "Email access" button only appears once there's an address on file, and email becomes required if two-step verification is on.

6 Permission levels & matrix

Access is granular. Set a base level per buyer, then override it folder-by-folder — and even file-by-file — so each buyer sees exactly what they should.

LevelWhat the buyer can do
No accessThe folder doesn't exist for them. Nothing shown.
ViewPreview files on screen in the in-browser viewer — but not download. Good for the P&L you want read, not walked off with.
DownloadEverything in View, plus pull the actual files down.
EditEverything in Download, plus upload into that folder.

How to set it

  • Base level comes from the level you picked when adding the buyer.
  • Per-folder override — click any cell in the permission grid to cycle it: No access → View → Download → Edit. So a buyer can, say, view the financials but only download the teaser.
  • Per-file override — expose or hide a single document for a specific buyer without touching the rest of the folder.
  • Activate / deactivate — one toggle kills or restores a buyer's access instantly, without deleting their history.

7 Buyer verification (2-step)

Two-step verification (MFA) adds a one-time email code on top of the access code — so only someone with the code and the buyer's inbox can get in.

  • Per-room toggle, on by default, with a clear On / Off state indicator next to the switch.
  • Trust this device for 10 days — a verified buyer isn't re-challenged on every visit.
  • Email becomes required to authorize a buyer while verification is on (the code has to go somewhere).
  • Firm default — a room can follow the brokerage default or override it; you can always snap it back to "Use firm default."
Reading the toggle
On = green pill and a tinted row; Off = grey pill. If a buyer has no email on file, the room warns you to add one before you can turn verification on.

8 The buyer link

  • Tokenized URL — every room has its own private link with an unguessable token. No buyer account required.
  • Regenerate link — issue a fresh link at any time, which instantly invalidates the old one. Use this if a link may have been forwarded.
  • Copy link is one click from the room and from the Rooms queue.
Remember
Before the first buyer is authorized, the raw link opens the room. After that, the link alone isn't enough — a code is required. So sharing the link early (pre-authorization) is different from sharing it once the room is locked.

9 What the buyer sees

Use Buyer view to preview the room exactly as an NDA'd buyer sees it — no surprises.

  • In-browser viewer — PDFs, images, and text open in a viewer inside the room.
  • Spreadsheets render in the browser too, client-side — so an Excel or CSV P&L can be read on screen and the file never leaves the confidential room. A view-only buyer reads the numbers without walking away with your working model.
  • Office files that can't render in-browser fall back to a clean download (for buyers with download rights).
  • The room carries your firm's brand — logo, name, colors — throughout.

10 Engagement & analytics

This is the part that tells you who's actually serious. Every view and download through the buyer link is captured, then rolled up for you.

Access log

A running record of every action taken through the buyer link, newest first, showing who did it (name and company), what they did, the document, and the timestamp. Actions are labeled distinctly — Signed in, Entered room, Viewed, Downloaded, Uploaded, and Asked a question — so you can read exactly what happened, not just "activity."

Drill down from the KPIs
The summary tiles at the top of Buyer engagement are clickable. Click Views or Downloads to filter the access log to just those events; click Buyers or Documents to jump straight to that breakdown.

Engagement by buyer

For each buyer: which documents they opened or downloaded, how many times, and when they were last in. Your follow-up radar.

Per-buyer activity trail

Expand any buyer in the "By buyer" list to see their full activity trail in order — a timeline grouped by day of everything they did and when: signed in at 10:00 PM, downloaded the 2024 P&L at 10:05, viewed the lease at 11:20, and so on. It's the play-by-play of a single buyer's visit, right alongside their per-document totals and read time.

"Hot buyer" flag

Automatically surfaces buyers who touched the key documents (P&L, financials, lease, tax returns) in the last 7 days. That's your call-today list.

Read time (time-on-page)

Not just that a buyer clicked, but how long they actually read each document — e.g. "Jane spent 6m 12s on the 2023 P&L." Timed honestly: the clock pauses when they switch tabs or minimize, so backgrounded time isn't counted as reading.

Engagement by document

For each file: views, downloads, unique buyers, and total read time — with the key financial and lease docs starred.

Firm-wide reports

The admin Reports page rolls it all up across every room: most-opened / most-downloaded documents, buyer engagement across all deals, and where your attention should go — each windowed to a time range you pick.

11 Alerts & Buyer Q&A

Real-time alerts

The instant a buyer first opens one of the key documents (P&L, financials, lease, tax returns), you get an email — once per buyer per doc, so it's signal, not noise. On by default, controllable in settings.

Buyer Q&A (private threads)

  • An authorized buyer can ask questions right inside the room — no separate email channel.
  • Private per buyer — each buyer sees only their own thread; buyers never see each other's questions.
  • Questions land in your inbox and in a "Buyer questions" panel, flagged Awaiting reply until you answer.
  • Reply inline; the buyer sees your answer next time they're in.

12 Document protection

Download watermarking

Every PDF download is stamped on every page with the buyer's name, email, timestamp, and your firm. A leaked document points straight back to whoever downloaded it. On by default, controllable in settings.

Redact before you share

On any PDF in the room, click Redact, drag a box across anything sensitive — an owner's name, an SDE figure, an address — across as many pages as you like, and click Apply redactions. The system permanently removes the covered content and files the result as a new "(redacted)" copy in the same folder; that redacted version is what buyers see and download. Your untouched original is kept as a private, broker-only file marked "Original · hidden," so you always have the full document for your own reference. Because the blacked-out text is physically deleted from the buyer's file, it can't be copied out, searched, or recovered from under the box — the classic "black box over live text" redaction leak can't happen here.

Confidential by default

Nothing is exposed to a buyer until they're vetted and gated. Combined with per-buyer codes, the permission matrix, verification, and watermarking, that's the whole philosophy: the seller's information stays protected at every step.

13 Seller interview (internal only)

Seller interview videos and transcripts can be attached to the room for the broker's reference.

Internal — buyers never see this
Seller interview material is clearly marked internal and is never shown to buyers. It's there to brief you and your team, not the buy side.

14 Room lifecycle

  • Create — standalone, from a seller call, or generated from a listing's marketing pack / CIM.
  • Close & archive — after a sale, archive the room. It's preserved with an archived banner, not deleted, so the record and its engagement history stay intact.
  • Reopen — if a deal comes back to life, reopen the archived room right where it left off.
  • Rooms queue — manage every active and archived room from one list, with buyer view, edit, upload, and copy-link a click away.

15 Admin settings

  • Data Room Access Email — the email a buyer/seller receives with the link, their code, and the upload note is fully editable under Admin Settings → Data Room Access Email (subject and body, with tokens like the business name, first name, link, and code). Make it sound like you.
  • Firm default verification — set whether new rooms default to two-step verification on or off; individual rooms can override.
  • Alerts & watermarking — both on by default and controllable in settings.

16 FAQ & troubleshooting

A buyer says the link doesn't work.

Once the first buyer is authorized the room locks, so the link alone won't open it — they need their access code. Re-send it with Email access on their row. If verification is on, they'll also get a one-time email code each new device.

How does someone upload documents to the room?

Give them Edit rights on the target folder, then Email access so they get the link and code. They open the link and can upload into any folder where they have Edit. There's no separate "upload link" — it's the room link plus Edit permission.

The room title just says "Data Room" with no business name.

The title reads "Data Room · [Business]" and pulls the business from the linked seller record. If it's blank or wrong, use the ✎ Rename control next to the title to set it directly — see "Renaming a room" in Creating a data room.

Can a buyer download something I only want them to read?

Set that folder (or file) to View, not Download. They'll read it in the in-browser viewer — spreadsheets included — but can't pull the file.

I need to cut off a buyer immediately.

Deactivate them with one toggle (keeps their history) or revoke access. To invalidate a link that may have been forwarded, regenerate the room link.

Can I tell whether a buyer is serious?

Check the "Hot buyer" flag and read time. A buyer who spent real minutes on the P&L and lease in the last week is your call-today.

Does the buyer need an account?

No. Buyers never sign in to the platform — link plus code (plus a one-time email code if verification is on).

What file types and sizes are supported?

PDF, Word, Excel, CSV, PowerPoint, images, and text; up to 25 MB per file on single upload, and up to 40 files at once on bulk upload.
