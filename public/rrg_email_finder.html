Email Finder — Help

What this is

A prospecting tool. Give it a city, state, and restaurant type and it pulls matching restaurants from Google, then visits each one’s website to find a public contact email. It builds a list you can export or hand to Bulk Email.

How emails are found

Google’s data does not include emails — it gives us each restaurant’s website. The finder then reads that public site (home, contact, and about pages) for a published address. Restaurants that only use a contact form won’t return an email; that’s normal — expect a partial hit rate.

1 · Find restaurants

Search by City & State or by ZIP code — use the toggle. Pick a type from the list (it maps to Google’s own categories, so the match is tight), choose how many results, and click Find restaurants. You’ll get names, addresses, phones, websites, and ratings in a few seconds. Google returns up to 60 per search — narrow by type or neighborhood and stack lists to cover a whole metro.

ZIP search is exact

When you search by ZIP, results are hard-filtered to that ZIP — Google’s search bleeds into neighboring ZIPs, so anything outside the one you asked for is dropped. Enter several at once (78701, 78702) to cover more ground; each ZIP is searched and filtered on its own, then merged.

Searches stack

Each new search adds to the list on screen instead of replacing it, and restaurants already listed are skipped — so you can run several types or ZIPs, build one combined list, then save or export it. Use Clear list to start over.

2 · Find emails

Click Find emails to crawl the websites. A progress bar fills as it works; emails drop into the table as they’re found. Tick Only rows with an email to hide the rest.

3 · Save & export

Name the list and Save as list — it’s stored here on its own, not mixed into your contacts or subscribers. Export any list to CSV to import into Bulk Email or work it however you like.

Setup

Uses your existing Google Maps API key (Admin). The Places API must be enabled on that same Google Cloud project, with billing on. If a search is denied, that’s almost always the cause.

Play it straight

These are published business addresses for B2B outreach. When you send, do it through Bulk Email so every message carries your identity and a one-click unsubscribe — that keeps you clean under CAN-SPAM and protects your sending reputation.

Email Finder — Features

What's inside

  • City / state / type search — targeted restaurant discovery via Google Places.
  • Up to 60 results per search, with ratings and review counts.
  • Website email crawl — reads home, contact, and about pages for a public address.
  • Smart email picking — prefers info@/reservations@ on the restaurant’s own domain; filters out tracking and asset junk.
  • Live progress — watch emails fill in as sites are crawled.
  • Emails-only filter — one click to hide rows without an address.
  • Saved lists — kept in their own store, separate from CRM and subscribers.
  • CSV export — take any list into Bulk Email or a spreadsheet.
  • Reuses your Google key — no new credentials to manage.
