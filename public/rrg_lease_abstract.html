Lease Abstract — Help

What this is

A concise summary of a lease’s key business terms — parties, premises, term, rent, options, charges, and risk items — for fast review and buyer packages. It never replaces the executed lease.

Edit in place

With Editing: On, click any value and type. Changes save automatically — watch for the “Saved ✓” chip. Turn editing off for a clean, read-only view.

Add rows

In edit mode, use + Add under Watch Items, Base Rent, and Critical Dates to add lines.

Redaction

Redact Landlord and Redact Tenant withhold those party names, replacing them with “Withheld — available under NDA.” Use this for buyer-facing copies before an NDA is signed; the guarantor follows the tenant.

Print / PDF

Print opens your browser’s print dialog — choose “Save as PDF” for a clean file. The toolbar and edit highlights are hidden automatically.

Confidential

Every abstract carries a confidentiality notice and disclaimer in the footer. Treat it as confidential work product.
