API Keys & Integrations

Connect FullServe to the outside services it leans on — Google for location photos, your mail provider for outbound email, and Twilio for text reminders. Keys and secrets are stored on the server only, never sent to browsers or included in backups.

Google Maps API key

Powers automatic location photos (Street View storefronts + Google Places business photos). Create a key in Google Cloud with the Street View Static and Places APIs enabled, then paste it here.
Loading…
Once set, a “Pull photo” button appears on every location and the location finder auto-fetches a storefront for each unit it adds.

Email (SMTP)

Outbound email for the app: contact emails, document sends, and alert digests. Enter your mail provider’s SMTP details (Gmail, SendGrid, etc.). Use the test button to confirm it works before relying on it.
Loading…
Gmail: use an app password (myaccount.google.com/apppasswords), host smtp.gmail.com, port 587. Leave the password blank when saving to keep the current one.

SMS (Twilio)

Outbound text messages for task reminders. Create a Twilio account, then paste your Account SID, Auth Token, and a Twilio phone number. Reps are texted at the phone number on their user profile.
Loading…
Get credentials at twilio.com (Console). Leave the token blank when saving to keep the current one.

Gmail sent-mail sync

Auto-logs emails reps send from Gmail onto the matching contact. Runs in the background for every rep who has connected Gmail (Account → Gmail); each sent email is matched to a contact by address and added to Tracked Emails. Reps can also pull on demand from the Tracked Emails page.

BizBuySell auto-import

How far back the Gmail lead scan looks. The very first scan reaches back the first number to catch history; every scan after only looks back the second, to grab what’s new. Applies system-wide to all reps.
